## 1. 폴더 구조

```
Assets/
├── [코드 루트]/
│   ├── Core/
│   ├── Gameplay/
│   ├── UI/
│   └── Data/
├── Scenes/
└── Prefabs/
```

**조직 방식**: 기능별(Feature-based) / 레이어별(Layer-based) / 혼합

## 2. 클래스 역할 및 명명

| 접미사 | 역할 | 예시 |
|--------|------|------|
| Manager | 전역 상태 관리, 서비스 진입점 | `GameManager`, `AudioManager` |
| Controller | 특정 오브젝트/흐름 제어 | `PlayerController`, `EnemyController` |
| System | 순수 로직, MonoBehaviour 없음 | `DamageSystem`, `ScoreSystem` |
| Handler | 이벤트/입력 처리 | `InputHandler`, `CollisionHandler` |
| [탐지된 접미사 추가] | ... | ... |

## 3. 디자인 패턴

> 탐지된 패턴만 포함한다.

### Singleton
- 구현 방식: `static Instance` 프로퍼티 + `DontDestroyOnLoad`
- 적용 클래스 예시: `GameManager`, `AudioManager`
- **규칙**: 새 Manager 작성 시 동일 패턴 적용

### Observer / Event
- 구현 방식: `UnityEvent` / C# `event Action` / 커스텀 이벤트 버스
- **규칙**: UI 콜백은 UnityEvent, 시스템 간 통신은 event Action
