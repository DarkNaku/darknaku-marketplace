## 1. 장르 특성 요약

Match-3 퍼즐의 본질은 **제한된 자원(이동 수 또는 시간) 안에 보드 상태를 목표 조건으로 변환하는 것**이다.
핵심 Aesthetic은 **Challenge**(제약 내 목표 달성)와 **Sensation**(콤보 터지는 시각·청각 쾌감)의 조합이다.

**장르 정의 요소 (없으면 Match-3가 아님)**
- 격자(Grid) 기반 보드
- 동일 요소 3개 이상 인접 → 제거 규칙
- 이동 수 또는 시간 제한
- 제거 후 위에서 새 요소 낙하(중력)

**장르 수익화 특징**
- 에너지(하트) 소진 → Interstitial 광고 또는 IAP
- 어려운 스테이지 직전 부스터 팝업이 핵심 페인포인트
- Continue(이동 수 추가)가 주요 충동 결제 상품

## 3. 장르별 섹션 가이드

### 3.1 코어 루프 작성 포인트

Match-3의 코어 루프는 반드시 아래 5단계를 포함해야 한다.

```
① 스테이지 선택 (월드맵/스테이지 선택 화면)
   → 하트 1개 소모 확인 팝업
② 게임플레이: 타일 스왑 → 매칭 판정 → 제거 → 낙하
③-A 클리어: 남은 이동 수에 따라 별 1~3개 + 재화 보상
③-B 실패: 하트 1개 소모 / [광고 시청으로 이동 수 +N] 또는 [재화 소모] 또는 [포기]
④ 결과 화면: 별 연출 → 보상 지급 → 다음 스테이지 잠금 해제
⑤ 월드맵 복귀 → 다음 스테이지 자동 하이라이트
```

### 14.1 보드 & 그리드 시스템

**보드 기본 구성**
| 항목 | 내용 |
|------|------|
| 보드 크기 | {가로} × {세로} 칸 |
| 셀 유형 | 일반 셀 / 장애물 셀 / 잠금 셀 / 이동 불가 셀 |
| 초기 배치 방식 | (랜덤 / 레벨 에디터 지정 / 혼합) |
| 매칭 방향 | 가로 / 세로 / 대각선 여부 |

**중력(낙하) 규칙**
```
1. 타일 제거 시 위쪽 타일이 빈 공간으로 낙하
2. 낙하 완료 후 상단에서 새 타일 생성 (색상: 랜덤 또는 가중치 적용)
3. 낙하 후 새로운 매칭 발생 시 → 연쇄(Cascade) 처리
4. 연쇄 종료 시 이동 가능 상태 복귀
```

**장애물 셀 종류 및 제거 조건**
| 장애물 유형 | 설명 | 제거 조건 | 레이어 수 |
|------------|------|-----------|-----------|
| {예: 얼음} | | 인접 매칭 N회 | |
| {예: 돌} | | | |
| {예: 쇠사슬} | | | |

**→ 만들어내는 Dynamic**: 보드 상태에 따라 매 판 다른 전략 요구 → 반복 플레이에도 신선함 유지
**→ 유발하는 Aesthetic**: Challenge (퍼즐 해결), Sensation (타일 터지는 시각 쾌감)

### 14.2 타일 종류 & 매칭 규칙

**기본 타일**
| 색상 | 아이콘/모양 | 비고 |
|------|------------|------|
| {색상 1} | | |
| {색상 2} | | |
| ... (총 {N}가지) | | |

**매칭 판정 규칙**
```
1. 플레이어가 인접 타일을 스왑
2. 스왑 후 3개 이상 동색 타일이 가로 또는 세로로 인접하면 매칭 성립
3. 매칭 불성립 시 스왑 취소 (원위치 애니메이션)
4. 스왑 유효 범위: 상하좌우 1칸 (대각선 불가 — 추정)
```

**특수 타일 생성 조건 및 효과**
| 특수 타일 | 생성 조건 | 효과 | 비고 |
|-----------|-----------|------|------|
| {예: 줄폭탄} | 4개 가로 매칭 | 가로 한 줄 제거 | |
| {예: 열폭탄} | 4개 세로 매칭 | 세로 한 열 제거 | |
| {예: 폭탄} | T/L자 또는 5개+ 매칭 | 주변 N칸 제거 | |
| {예: 무지개} | 5개 직선 매칭 | 지정 색상 전체 제거 | |

**특수 타일 조합 효과**
| 조합 | 효과 |
|------|------|
| 줄폭탄 + 열폭탄 | 십자 제거 |
| 폭탄 + 줄폭탄 | 가로 3줄 제거 |
| 무지개 + {특수} | 전체 {특수} 발동 |

**→ 만들어내는 Dynamic**: 특수 타일 조합 전략 수립 → 고점수 달성 욕구
**→ 유발하는 Aesthetic**: Sensation (대규모 제거 쾌감), Challenge (최적 조합 탐색)
