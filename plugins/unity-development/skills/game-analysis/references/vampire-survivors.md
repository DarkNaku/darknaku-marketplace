## 1. 장르 특성 요약

뱀서라이크의 본질은 **한 번의 런(Run) 안에서 성장과 생존을 동시에 추구하는 것**이다.
플레이어는 이동만 담당하고 공격은 자동으로 이루어지며, 레벨업마다 무기·스킬을 선택하여
자신만의 빌드를 구성해 점점 강해지는 적 웨이브를 생존한다.

핵심 Aesthetic은 **Challenge**(빌드 최적화, 생존 한계 도전)와 **Discovery**(새 무기/조합 발견)의 조합이다.
런이 실패해도 **메타 진행**(런 간 영구 성장)으로 좌절이 아닌 동기로 전환되는 구조가 핵심이다.

**장르 정의 요소 (없으면 뱀서라이크가 아님)**
- 런 기반 (세션 = 1회 런, 퍼마데스)
- 자동 공격 (이동만 플레이어 담당)
- 레벨업 시 무기/스킬 선택 (매 레벨업마다 빌드 분기)
- 적 웨이브 자동 스포닝 (시간 경과에 따라 강해짐)
- 런 종료 후 메타 재화 획득 → 영구 성장 트리

**장르 수익화 특징**
- 에너지 시스템이 없거나 약함 → 주요 페인포인트: 빌드 선택지 제한, 캐릭터 잠금
- IAP: 캐릭터/무기 잠금 해제, 메타 성장 가속 재화, 광고 제거
- Rewarded 광고: 런 중 부활 1회, 런 종료 후 메타 재화 2배

**타 장르와의 핵심 차이점**
| 항목 | 뱀서라이크 | Match-3/타이쿤 |
|------|------------|----------------|
| 실패의 의미 | 런 재시작 (재화 일부 보존) | 에너지 1개 소모 |
| 에너지 시스템 | 없음 또는 약함 | 핵심 리텐션 장치 |
| 세션 길이 | 10~30분 (1회 런) | 2~5분 |
| 난이도 원천 | 빌드 선택 실수, 웨이브 밀도 | 스테이지 설계, 이동 수 제한 |

## 3. 장르별 섹션 가이드

### 3.1 코어 루프 작성 포인트

뱀서라이크의 코어 루프는 **런 내부 루프**와 **런 간 루프** 두 가지를 모두 기술해야 한다.

**런 내부 루프 (세션 = 1회 런)**
```
① 캐릭터 선택 + 시작 무기 선택 (로비)
② 게임 시작: 플레이어 이동 + 자동 공격
③ 경험치 구슬 획득 (적 처치) → 레벨업
④ 레벨업 선택지 N개 중 1개 선택 (무기 또는 스킬)
⑤ ②~④ 반복 → 빌드 완성도 향상
⑥ 보스 등장 (일정 시간 또는 조건)
⑦-A 생존 성공: 런 클리어 → 메타 재화 획득
⑦-B 사망: 런 종료 → 메타 재화 일부 획득 → 재시작
```

**런 간 루프 (메타 루프)**
```
① 런 종료 → 획득 메타 재화 확인
② 영구 성장 트리에서 업그레이드 선택
③ 새 캐릭터/무기 잠금 해제 (조건 달성 시)
④ 더 나은 빌드로 런 재시작 → ①로 반복
```

| 빌드명 | 핵심 무기 | 서포트 스킬 | 강점 | 약점 |
|--------|----------|------------|------|------|
| | | | | |

**→ 만들어내는 Dynamic**: 조합 발견 → 공유·전파 → 커뮤니티 메타 형성
**→ 유발하는 Aesthetic**: Discovery (숨겨진 조합 발견), Fellowship (빌드 공유)

### 14.5 적 웨이브 스포닝 시스템

**적 유형 분류**
| 유형 | 특성 | 등장 구간 | 경험치 |
|------|------|-----------|--------|
| 일반 적 | 낮은 HP, 수적 우세 | 전 구간 | 낮음 |
| 엘리트 적 | 높은 HP, 특수 공격 | 중반~ | 높음 |
| 미니 보스 | 주기적 등장, 특수 능력 | N분마다 | 매우 높음 |
| 최종 보스 | 런 마지막 | 목표 시간 도달 시 | 런 종료 |

**웨이브 밀도 곡선**
```
[시간 경과에 따른 적 밀도 변화]
0~5분:   적 1~5마리 동시 → 학습 구간
5~15분:  적 10~30마리 → 코어 게임플레이
15~25분: 적 50+마리 → 빌드 완성 필요 구간
25~30분: 최고 밀도 + 보스 → 생존 한계 테스트
```

**스포닝 규칙**
```
1. 플레이어 화면 밖 일정 거리에서 스폰
2. 스폰 방향: {랜덤 / 플레이어 이동 방향 기준 / 전방위}
3. 웨이브 간격: {N초마다 새 웨이브} (추정)
4. 특수 이벤트: {예: 일정 시간마다 특정 적 집중 등장}
```

**보스 패턴**
| 보스명 | 등장 조건 | HP (추정) | 공격 패턴 | 드롭 |
|--------|-----------|-----------|----------|------|
| | | | | |

**→ 만들어내는 Dynamic**: 웨이브 밀도 증가 → 플레이어 긴장감 상승 → 이동 최적화 강제
**→ 유발하는 Aesthetic**: Challenge (생존 한계 도전), Sensation (대규모 처치 쾌감)

### 14.6 메타 진행 시스템 (런 간 영구 성장)

**메타 재화 종류**
| 재화명 | 획득 방법 | 용도 |
|--------|-----------|------|
| {메인 메타 재화} | 런 종료 시 획득 | 영구 업그레이드 트리 |
| {보조 재화} | 특수 조건 | 캐릭터/무기 언락 |

**영구 업그레이드 트리**
| 카테고리 | 업그레이드 항목 | 최고 레벨 | 레벨당 효과 | 비용 |
|----------|----------------|-----------|------------|------|
| 체력 | 최대 HP 증가 | | +{N}% | |
| 공격 | 기본 데미지 증가 | | +{N}% | |
| 이동 | 이동 속도 증가 | | +{N}% | |
| 경제 | 메타 재화 획득량 증가 | | +{N}% | |
| 기타 | {고유 항목} | | | |

**캐릭터/무기 잠금 해제 조건**
| 대상 | 해제 조건 | 비고 |
|------|-----------|------|
| {캐릭터명} | {조건 — 예: 런 N회 클리어} | |
| {무기명} | {조건 — 예: 특정 적 N마리 처치} | |

**메타 진행의 심리적 효과**
```
런 실패 → "메타 재화 획득했으니 성장함" → 재시작 동기 유지
런 성공 → 더 많은 메타 재화 → 더 큰 성장 → 더 어려운 도전
```

**→ 만들어내는 Dynamic**: 실패도 성장으로 전환 → 좌절 → 재도전 사이클 유지
**→ 유발하는 Aesthetic**: Challenge (점진적 도전), Submission (성장의 누적 쾌감)

## 5. 품질 체크 추가 항목 (뱀서라이크 전용)
