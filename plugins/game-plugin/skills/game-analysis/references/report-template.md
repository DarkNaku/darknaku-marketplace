## 3. Dynamics — 게임 루프 & 시스템 흐름

> Mechanics가 실행될 때 나타나는 행동 패턴. 구현보다 "결과"에 집중.

### 3.1 코어 루프 (Core Loop)
```
[세션 내 1회 반복 단위 — 최대한 구체적으로]

① {단계 1 — 화면/상황}
② {단계 2 — 플레이어 행동}
③ 성공: {보상 내용}
   실패: {소모 자원} / {재시도 옵션}
④ {결과 화면 처리}
⑤ {다음 반복으로 연결}
```

### 3.2 메타 루프 (Meta Loop)
```
[세션 간 장기 진행 — 플레이어를 계속 돌아오게 만드는 구조]

① 코어 루프 반복 → {자원 누적}
② 누적 자원으로 → {메타 시스템 성장}
③ 성장 결과 → {코어 루프 변화 / 새 콘텐츠 개방}
④ {재방문 동기} → ①로 반복
```
