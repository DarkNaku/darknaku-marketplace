## 1. 장르 특성 요약

하이브리드 캐주얼 타이쿤의 본질은 **제한된 시간 안에 몰려드는 고객의 주문을 처리하여 수익을 극대화하는 것**이다.
코어 루프는 스테이지 클리어 방식이지만, 메타 레이어에서 시설·장비·캐릭터를 업그레이드하여 처리 능력을 성장시킨다.

핵심 Aesthetic은 **Submission**(바쁜 리듬에 몰입하는 쾌감)과 **Challenge**(타이트한 시간 안에 모든 주문 처리)의 조합이다.

**장르 정의 요소 (없으면 타이쿤이 아님)**
- 스테이션(조리대·계산대 등) 기반 워크플로우
- 고객 AI — 도착, 주문, 인내심(분노 게이지), 이탈
- 시간 제한 또는 고객 수 목표
- 메타 업그레이드로 속도·용량·자동화 향상

**장르 수익화 특징**
- 에너지 시스템이 있는 경우 하트 소진이 주요 페인포인트
- 주요 IAP: 업그레이드 가속 재화, 고급 장비 팩
- Rewarded 광고: 스테이지 종료 후 수익 2배, 속도 임시 부스트

## 3. 장르별 섹션 가이드

### 3.1 코어 루프 작성 포인트

타이쿤의 코어 루프는 반드시 아래 구조를 포함해야 한다.

```
① 스테이지/매장 선택
   → 에너지 소모 확인 (에너지 시스템이 있는 경우)
② 게임플레이 시작
   → 고객 도착 (간격: {추정}초)
   → 플레이어: 주문 확인 → 스테이션 이동 → 재료 처리 → 서빙
   → 고객 인내심 게이지 감소 중 — 이탈 전 서빙 완료 필요
③-A 클리어: 목표 수익/점수 달성 → 별 1~3개 + 재화 보상
③-B 실패: 목표 미달 → 재시도 또는 포기
   (실패 시 에너지 소모 여부: 게임마다 다름)
④ 결과 화면: 수익 집계 + 보상 연출 → 업그레이드 화면 진입 유도
⑤ 업그레이드 적용 → 다음 스테이지 또는 동일 스테이지 재도전
```
